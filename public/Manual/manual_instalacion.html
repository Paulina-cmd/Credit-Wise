Manual de Instalación

Proyecto: CreditWise | Versión: 1.0 | Fecha: Octubre 2025

1. Introducción

Este manual explica el proceso de instalación y configuración de la aplicación CreditWise, desarrollada con FastAPI y MySQL. Su propósito es guiar paso a paso la correcta instalación del sistema tanto en entornos locales como de prueba.

2. Requisitos del sistema

  • Sistema operativo: Windows 10 / Ubuntu 20.04 o superior.
  • Python 3.10+
  • MySQL Server 8.0+
  • Git
  • Navegador web moderno (Chrome, Edge o Firefox)

3. Preparación del entorno

Verificar instalación de Python

python --version
pip --version

Instalar MySQL

CREATE DATABASE creditwise_db;

Instalar Git

git --version

4. Clonar el repositorio

git clone https://github.com/Paulina-cmd/creditwise.git
cd CreditWise

5. Instalar dependencias

pip install -r requirements.txt

6. Configuración del entorno

Crea un archivo .env con el siguiente contenido:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD="" 
DB_NAME=creditwise_db
PORT=8000

7. Ejecutar la aplicación

uvicorn main:app --reload

Luego abre tu navegador y entra a: http://127.0.0.1:8000

8. Verificación

Accede a /docs para comprobar la documentación interactiva de la API y probar las rutas del sistema.

9. Problemas comunes

Problema Posible causa Solución
ModuleNotFoundError Dependencia faltante Ejecutar pip install -r requirements.txt
Error de conexión a la BD Datos incorrectos en .env Revisar credenciales y que MySQL esté ejecutándose
Puerto en uso Otro proceso usa el 8000 Cambiar el valor de PORT en .env

10. Desinstalación

Para eliminar la aplicación:

  • Borra la carpeta del proyecto.
  • Elimina la base de datos desde MySQL:
DROP DATABASE creditwise_db;
